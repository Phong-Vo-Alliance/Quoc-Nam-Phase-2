## 7. Toggle Panel

### 7.1 Desktop

```
Panel mở (mặc định):
┌─────────────┐  ┌─────────────────────────┐  ┌──────────────────┐
│  LEFT       │  │       CHAT MAIN         │  │   RIGHT PANEL    │
│  PANEL      │  │                         │  │                  │
└─────────────┘  └─────────────────────────┘  └──────────────────┘

Click [X] → Panel đóng:
┌─────────────┐  ┌───────────────────────────────────────────────┐
│  LEFT       │  │                    CHAT MAIN                  │
│  PANEL      │  │                  (Full width)                 │
└─────────────┘  └───────────────────────────────────────────────┘

Click [ℹ️] ở header → Panel mở lại
```

### 7.2 Mobile

```
Mặc định: Panel ẩn (chỉ hiện Chat)

Click [ℹ️] → Panel slide in từ phải (overlay)
Click [X] hoặc outside → Panel slide out
```
