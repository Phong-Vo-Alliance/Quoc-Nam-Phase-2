## 3. Thông Tin Conversation Card

| Thành phần   | Mô tả                        |
| ------------ | ---------------------------- |
| Avatar       | Ảnh nhóm hoặc icon mặc định  |
| Tên nhóm     | Tên conversation             |
| Last message | Tin nhắn gần nhất (truncate) |
| Work Type    | Loại công việc (badge)       |
| Thời gian    | Thời điểm tin nhắn cuối      |
| Unread badge | 🔴 Số tin chưa đọc           |

---

## 4. Tính Năng Lọc

### 4.1 Lọc Theo Work Type

```
┌─────────────────────────────┐
│  Work Type           [▼]   │
├─────────────────────────────┤
│  ◉ Tất cả                  │
│  ○ Nhận hàng               │
│  ○ Kiểm đếm                │
│  ○ Vận chuyển              │
│  ○ Báo cáo                 │
└─────────────────────────────┘
```

### 4.2 Lọc Theo Variant

```
┌─────────────────────────────┐
│  Variant             [▼]   │
├─────────────────────────────┤
│  ◉ Tất cả                  │
│  ○ Kho A                   │
│  ○ Kho B                   │
│  ○ Kho C                   │
└─────────────────────────────┘
```

---

## 5. Tìm Kiếm

### 5.1 Tìm Theo Tên

```
[🔍 "Kiểm hàng"]
        │
        ▼
Kết quả: Các conversation có tên chứa "Kiểm hàng"
```

### 5.2 Debounce

- Chờ 300ms sau khi user ngừng gõ
- Không gọi API mỗi ký tự

## 6. Trạng Thái Conversation

### 6.1 Selected State

```
Chưa chọn:                        Đã chọn:
┌─────────────────────────┐      ┌─────────────────────────┐
│  Nhóm ABC               │      │▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓│
│  Last message...        │      │▓ Nhóm ABC              ▓│
│                   10:30 │      │▓ Last message...       ▓│
└─────────────────────────┘      │▓                 10:30 ▓│
     Background: white            └─────────────────────────┘
                                       Background: highlight
```

### 6.2 Unread Badge

```
Có tin chưa đọc:
┌─────────────────────────────────────────────────────────┐
│  Nhóm ABC                                         🔴 5  │
│  ↑ Badge hiển thị số tin chưa đọc                       │
└─────────────────────────────────────────────────────────┘

Khi click vào conversation → Badge biến mất (đã đọc)
```
