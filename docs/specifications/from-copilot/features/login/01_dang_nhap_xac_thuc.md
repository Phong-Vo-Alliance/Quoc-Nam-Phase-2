## 3. Validation Rules

| Trường   | Validation   | Lỗi hiển thị                 |
| -------- | ------------ | ---------------------------- |
| Email    | Required     | "Vui lòng nhập email"        |
| Email    | Format email | "Email không hợp lệ"         |
| Mật khẩu | Required     | "Vui lòng nhập mật khẩu"     |
| Mật khẩu | Min 6 ký tự  | "Mật khẩu tối thiểu 6 ký tự" |

## 4. Các Trạng Thái UI

### 4.1 Trạng Thái Button

| Trạng thái | Hiển thị                  |
| ---------- | ------------------------- |
| Default    | "ĐĂNG NHẬP"               |
| Loading    | "ĐANG XỬ LÝ..." + spinner |
| Disabled   | Màu mờ, không click được  |

### 4.2 Thông Báo Lỗi

Lỗi validation:
┌───────────────────────────────────────────────────────────┐
│  Email                                                    │

## 6. Bảo Vệ Trang

### 6.1 Protected Routes

Các trang yêu cầu đăng nhập:

- `/portal` - Trang chính
- `/portal/workspace` - Workspace view
- `/portal/lead` - Leader view
- `/portal/settings` - Cài đặt

### 6.2 Redirect Logic

```
User truy cập protected route
        │
        ▼
Kiểm tra đã đăng nhập?
        │
   ┌────┴────┐
   │         │
   ▼         ▼
[Có]      [Không]
   │         │
   ▼         ▼
Cho phép   Redirect về
truy cập   /login
```
