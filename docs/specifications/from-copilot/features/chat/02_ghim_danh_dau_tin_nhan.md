# 02. Ghim & Đánh Dấu Tin Nhắn

> **Mục đích:** Mô tả tính năng Pin và Star tin nhắn

---

## 1. So Sánh Pin vs Star

| Tính năng     | 📌 Ghim (Pin)     | ⭐ Đánh dấu (Star) |
| ------------- | ----------------- | ------------------ |
| **Ai có thể** | Leader, Admin     | Tất cả             |
| **Ai thấy**   | Tất cả thành viên | Chỉ cá nhân        |
| **Hiển thị**  | Banner đầu chat   | Tab "Đã đánh dấu"  |
| **Giới hạn**  | Có                | Không              |
| **Mục đích**  | Thông báo chung   | Bookmark cá nhân   |

---

## 2. Ghim Tin Nhắn (Pin)

### 2.1 Cách Ghim

```
1. Hover tin nhắn
        │
        ▼
2. Click [📌] hoặc menu [⋮] → "Ghim tin nhắn"
        │
        ▼
3. Tin nhắn được ghim
        │
        ▼
4. Hiển thị trong banner đầu chat
```

### 2.2 Banner Tin Ghim

```
┌─────────────────────────────────────────────────────────────────────────┐
│  📌 TIN NHẮN ĐÃ GHIM (2)                                    [Xem ▼]   │
│                                                                         │
│  "Họp team vào 2h chiều mai tại phòng họp A"              - Minh Anh  │
└─────────────────────────────────────────────────────────────────────────┘
```

│  📌 TIN NHẮN ĐÃ GHIM                                           [X]     │

## 3. Đánh Dấu Tin Nhắn (Star)

### 3.1 Cách Đánh Dấu

```
1. Hover tin nhắn
        │
        ▼
2. Click [⭐] hoặc menu [⋮] → "Đánh dấu"
        │
        ▼
3. Tin nhắn được thêm vào "Đã đánh dấu"
```

### 3.2 Xem Tin Đã Đánh Dấu

Vào tab "Đã đánh dấu" trong Right Panel:

```
┌─────────────────────────────────────────────────────────────────────────┐
│  ⭐ TIN NHẮN ĐÃ ĐÁNH DẤU (5)                                           │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │  Huyền                                             14:20        │   │
│  │  Link tài liệu: https://docs.google.com/...                     │   │
│  │  [Đến tin nhắn]                                   [⭐ Bỏ dấu]   │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                         │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │  Leader Hương                                      09:00        │   │
│  │  Số điện thoại khách: 0901-234-567                              │   │
│  │  [Đến tin nhắn]                                   [⭐ Bỏ dấu]   │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

## 4. Navigation

### 4.1 Jump to Message

Khi click "Đến tin nhắn":

```
1. Click [Đến tin nhắn]
        │
        ▼
2. Chat scroll đến vị trí tin nhắn gốc
        │
        ▼
3. Tin nhắn được highlight tạm thời (2-3s)
```
