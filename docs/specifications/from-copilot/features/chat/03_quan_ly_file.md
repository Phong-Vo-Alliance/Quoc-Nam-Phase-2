# 03. Quản Lý File & Tài Liệu

> **Mục đích:** Mô tả tính năng upload, xem và quản lý file

---

## 1. Upload File

### 1.1 Các Cách Upload

| Cách        | Mô tả                        |
| ----------- | ---------------------------- |
| Click [📎]  | Mở file picker               |
| Drag & Drop | Kéo thả file vào chat        |
| Paste       | Ctrl+V ảnh từ clipboard      |
| Camera      | Click [📷] chụp ảnh (mobile) |

### 1.2 Loại File Hỗ Trợ

| Nhóm        | Extensions                     | Max Size |
| ----------- | ------------------------------ | -------- |
| 🖼️ Hình ảnh | .jpg, .png, .gif, .webp        | 10MB     |
| 🎥 Video    | .mp4, .webm, .mov              | 50MB     |
| 📄 Tài liệu | .pdf, .doc, .docx, .xls, .xlsx | 25MB     |
| 📦 Nén      | .zip, .rar                     | 50MB     |

### 1.3 Upload Progress

```
┌─────────────────────────────────────────────────────────────────────────┐
│  FILE ĐANG UPLOAD                                                       │
│  ┌──────┐ ┌──────┐ ┌──────┐                                            │
│  │ IMG  │ │ IMG  │ │ PDF  │                                            │
│  │ 75%  │ │ 100% │ │ 30%  │                                            │
│  │ ████ │ │ ████ │ │ ██   │                                            │
│  │ [x]  │ │ [✓]  │ │ [x]  │                                            │
│  └──────┘ └──────┘ └──────┘                                            │
│                                                                         │

• Đang upload: Hiện % và progress bar
• Upload xong: Hiện ✓
```
