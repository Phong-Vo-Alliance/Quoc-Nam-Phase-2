## 6. Gửi Tin Nhắn

### 6.1 Cách Gửi

| Cách          | Mô tả                       |
| ------------- | --------------------------- |
| Click nút Gửi | Click [➤]                   |
| Enter         | Nhấn Enter (không có Shift) |
| Ctrl+Enter    | Xuống dòng                  |

### 6.2 Trạng Thái Gửi

```
Đang gửi:    ⏳ (spinner)
Đã gửi:      ✓
Đã đọc:      ✓✓
Lỗi:         ⚠️ [Gửi lại]
```

## 7. Scroll & Load More

```
Scroll lên đầu:
┌─────────────────────────────────────────────────────────────────────────┐
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │              ⏳ Đang tải tin nhắn cũ...                         │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                         │
│  [Tin nhắn cũ hơn]                                                     │
│  ...                                                                    │
│  [Tin nhắn mới nhất]                                                   │
│                                                                         │

```

